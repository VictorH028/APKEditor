Mi ocjetivo es crear un diseño tipo IDE de ingeniería inversa, paneles, árbol de archivos, editor Smali, consola de logs, progreso y tema oscuro/neón.

Esta no era mi idea inisial por lo que estare migrando a el codigo a `JavaFX` + `AtlantaFX` + `RichTextFX` que espero que sea suficiente para mi resultado final.

**¿Porque JavaFX?**

Porque el diseño que busco necesita cosas que JavaFX maneja muy bien:

| Elemento | Texnologia | 
| ------------- | -------------- | 
| Sidebal futurista | JavaFX + CSS | 
| Arbol APK | TreeView |
| Explorador de archivos | TreeView |

> Despues termino la tabla
